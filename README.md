# AvtoLux — характер в деталях

Демонстрационный концепт сайта студии тонировки и детейлинга в Санкт-Петербурге. Не является официальным сайтом компании.

Сайт: https://perihk.github.io/avtolux-demo/

Статические HTML, CSS и JavaScript. Фото и шрифты хранятся в репозитории. Источники фотографий, отзывов и бизнес-фактов описаны в [SOURCES.md](SOURCES.md). Указанные там пути `dist/assets/` соответствуют папке `assets/` в этом репозитории.

Публикация: GitHub Pages из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Изменения в `main` автоматически публикуются.

В демо работают меню, смена фотографий обложки, раскрытие услуг, фильтры галереи, просмотр фотографий и переключение отзывов. Формы, онлайн-запись и обработка заявок не подключены.
